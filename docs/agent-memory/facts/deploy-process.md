Пользователь подтвердил обязательный процесс 11.11.2026.

- Прямой доступ к боевому серверу и выполнение на нём команд запрещены.
  Сохранённые доступы и прежние инструкции выкатки не дают разрешения
  подключаться, проверять сервер через SSH, менять настройки или контейнеры.
- Изменения готовятся в dev соответствующего репозитория. Если dev нет,
  её нужно создать. Передача идёт через MR на рассмотрение Андрею.
- Сообщения коммитов должны быть короткими и предметными. Перед отправкой
  пользователь проверяет состав изменений и сообщения, затем согласовывает
  отправку. До согласования push не выполняется.
- Разработка, запуск и проверки выполняются локально.

**Почему** — пользователь прямо запретил работу на боевом сервере и определил
единственный процесс передачи изменений через GitLab и Андрея.

**Как применять** — сверять AGENTS.md перед сетевыми изменениями. Готовить
локальные изменения и результаты проверок, затем показать их пользователю
для согласования отправки. Установочные команды в docs/INSTALL.md
адресованы администратору установки.

Связано — [[mbk-production-setup]], [[gitlab-access-map]].
