В боевой аналитике `turn_completed` с `action = ask` и `field = client.name`
пишется и там, где клиент не написал ни слова. За 30 дней до 15.09.2026 из 299
сессий, «оборвавшихся на вопросе об имени», реплики клиента в
`dialog_messages` были только у 35. У 44 из оставшихся 264 сессий, которые
ещё лежали в `sessions`, в `state.chat_history` нет ни одной реплики с
`role = user`. Это открытые и брошенные окна чата, а не уход с вопроса.

**Как применять:** при подсчёте обрывов по вопросам брать только
`session_id`, у которых есть строка `dialog_messages` с `role = 'client'`
(таблица пишется с 20.08.2026). В `sessions` ключ — `id`, а не `session_id`.
Событие `lead_submitted` есть с 07.09.2026 — долю лидов считать с этой даты.

Цифры на 15.09.2026, только разговоры с текстами, 30 дней: анкету начали 287,
закончили 160; обрыв на имени 12%, на сумме 18%, регион и занятость по 6%,
остальные вопросы 0-5%, «аналитические» (доход, марка, второй объект) — 0-2%.
После конца анкеты телефон дают 38 из 47 (с 07.09). Используется в
предложении облегчения анкеты Михаилу — см. `docs/agent-memory/SESSION.md`.

Скрипты чтения лежали в scratchpad сессии (`db.py` — соединение read-only,
доступы у пользователя; значения здесь не хранить).
