## Исправления прежнего предложения

- «Не дольше трёх лет» как общее правило неверно. Проверено 31.10.2026:
  п. 2 ст. 213.14 127-ФЗ устанавливает общий срок до пяти лет; до трёх —
  для утверждения по п. 4 ст. 213.17. Текст закона:
  https://www.consultant.ru/document/cons_doc_LAW_39331/969d68218759cf2f51043317655a0566bf29637e/.
  Старую формулу v3 нельзя ни автоматически сокращать до 36 месяцев,
  ни считать юридически достаточной моделью применимости процедуры.
- «На имени отваливаются 31%» не означает 31% начавших анкету:
  в старом отчёте это 123 из 401 обрыва (30,7%); от 1214 начавших — 10,1%.
  Это распределение обрывов, а не доказанный эффект вопроса об имени.
- «80%» — 213 из 267 квалификаций с продуктом, а не доля всей выручки.
